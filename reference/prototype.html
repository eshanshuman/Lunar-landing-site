Why

Data

This build uses synthetic sample data with realistic shapes: the Sun circles the sky once per ~29.5 days at a height set by latitude, Earth wobbles slowly near the horizon (libration), and each skyline is generated, not measured. Step 2 swaps in JPL Horizons Sun/Earth positions and LOLA terrain horizons using the same data format. Site coordinates are published values still to be re-checked against NASA sources.
